Диана — модель полива растений, 200 записей

1. Откройте Diana_Greenhouse_Colab.ipynb в Google Colab через «Загрузить блокнот».
2. Выполните все ячейки по порядку: данные, проверка, разделение 160/40, нормализация, обучение, оценка.
3. Последняя ячейка скачает Diana_Streamlit_ready.zip.
4. Распакуйте его и откройте терминал в папке.
5. python -m pip install -r requirements.txt
6. python -m streamlit run app.py

Данные синтетические, независимые записи, seed=2026. Это учебная классификация, метки заданы условной логикой из инструкции для теплицы. Не является экспериментом по экономии воды. Приложение действительно передает три введенных числа обученному Pipeline (нормализация + дерево). Модель и зависимости лучше заново экспортировать из вашей Colab-сессии.

Для защиты: X — температура, влажность воздуха и почвы; y — необходимость полива. Нормализация обучается только на 160 строках. Оценка проводится на 40 отложенных строках. Дерево не требует нормализации, она добавлена для демонстрации этапа подготовки.
